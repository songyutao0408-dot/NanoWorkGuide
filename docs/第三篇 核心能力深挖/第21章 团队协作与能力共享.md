# 第21章 · 团队协作与能力共享

[第18章](</第三篇 核心能力深挖/第18章 把方法蒸馏成技能>)讲过"1人摸索，全组织受益"这个理念，这一章把它落到具体操作上——"团队"是纳米Work里查看和使用同事公开内容的地方，也是让个人能力真正变成组织能力的入口。

## 什么是"团队"

团队是你查看组织/同事公开的专家、Skill、任务、项目的地方。你可以直接使用公开的专家/Skill，也可以查看公开任务的对话过程及交付物、学习优秀案例；对于公开项目，你可以申请协同加入。

点击左侧导航栏"团队"进入，会看到按组织架构展示的公共智能体和成员列表。

![团队页面：组织公共智能体](/screenshots/p21-team-experts.png)

## 1. 查看及使用团队专家/Skill

- 点击组织树的不同层级，可查看每个层级公开的智能体或 Skill。
- 点击组织树里的个人，可进入个人主页，查看这个人公开的智能体/Skill/任务/项目。
- 公开的智能体可以点击直接进入对话，公开的 Skill 可以点击直接调用。

这意味着，如果同事已经训练出一个好用的"法务合规顾问"或者"HR政策助手"，你不需要重新训练一个，直接找到、直接用就行。

## 2. 查看及使用公开任务

- 如果个人主页有公开任务，可以查看并做同款任务。
- 点击个人主页的"公开任务"tab，选中你感兴趣的某一条任务，进入任务详情页，可以看到这个任务完整的对话过程和结果交付物。
- 点击任务详情页右侧的"做同款"，可以复用该案例的 Agent、Skill，做同款任务。

公开的任务，如同优秀的案例，可以看到身边优秀的人是如何发起任务、与 Agent 对话的；做同款能一键学习优秀经验，减少自己摸索的时间。

## 3. 查看公开项目及申请协同

- 点击个人主页的"公开项目"tab，可以看到所有公开项目，点击某一项目右侧"查看详情"，进入该项目详情页。
- 详情页包含该项目的任务、知识、专家、成员，其中"知识"可以点击查看，"任务/专家/成员"仅支持查看，不可点击。
- **申请协同**：点击项目详情页右上角"申请协同"，在弹窗中填入申请理由，项目负责人通过后，可加入该项目。加入后该项目右上角会显示"已在该项目"。

## 4. 公开自己的专家/Skill/项目

::: tip 重要提醒
在纳米Work企业版里，个人在搭建智能体、Skill、项目时，**默认搭建后为公开状态**，会展示在你的个人主页里，组织全员可见并使用。
:::

这是"能力沉淀"能真正生效的关键设计——不需要你额外做什么，你训练的专家、创建的技能，天然就是全组织共享的资产。

如果某个专家、Skill 或项目涉及敏感信息，不想让同事看到，可以手动修改可见范围：

- **修改专家可见状态**：点击侧边栏"专家"，在专家页面顶部点击"我的专家"，找到想要修改的智能体，点击右上角"…"，选择"仅对自己可见"即可。
- **修改 Skill 可见状态**：路径类似，"专家→技能宝典→我创建的"，找到需要修改状态的 Skill，点击右上角"…"，选择"仅自己可见"即可。
- **修改项目可见状态**：点击左侧边栏"项目"，选择想要修改状态的项目，点击右上角"…"，选择"仅自己可见"即可。

另外要注意的是：**公开任务需要你手动处理**，不是自动公开。操作方式：点击左侧边栏"任务"，选择想要公开至团队的任务，点击右上角"分享"，选择该任务的对话，确认完成后，在页面右下角选择"公开（团队可用）"即可公开这条任务。

## 5. 邀请同事加入项目

在同事的个人主页右侧，点击"邀请加入项目"，对该同事进行邀请；弹窗中选择要邀请这位同事加入的项目，邀请无需审批，点击确认后，该同事即刻加入项目。

## 6. 加入项目后协作

申请协同、被邀请加入项目成功后，可以在左侧"项目"tab 中进行协同工作。项目内的具体功能操作，可以参考[第5章 项目与知识库](</第一篇 快速上手/第5章 项目与知识库>)的介绍。

---

## 这一章的核心提醒

"团队"这个模块的价值，本质上是把[第18章](</第三篇 核心能力深挖/第18章 把方法蒸馏成技能>)讲的"人走了、能力留下来"往前推了一步——不需要等人离职，只要专家/Skill/项目默认是公开状态，**从被创建的那一刻起，就已经是全组织能调用的资产**。

如果你的团队有明确的信息隔离需求（比如某些客户资料只想让特定项目组看到），记得主动去检查一下自己创建的内容是不是默认公开的，按需调整成"仅自己可见"。
