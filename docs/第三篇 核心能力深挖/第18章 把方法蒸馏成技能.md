# 第18章 · 把骨干方法蒸馏成技能

[第14章](</第二篇 实战案例/第14章 攒资产>)讲过"攒资产"的价值——把经验沉淀下来，不随人走。这一章讲具体怎么操作：如何把一次成功的重复性工作，变成一个可以被反复调用、甚至被全公司共享的"技能"。

## 什么是"技能"

技能是给 AI 专家装配的能力插件。专家本身负责理解你的需求、做判断、给结论；技能负责帮专家调用外部工具、执行具体动作——比如搜索网页、生成视频、处理 PDF、操作日历。一个专家装了什么技能，就多了什么本事。

**技能宝典**是纳米Work内置的工具库，汇聚了覆盖多个场景的 AI 技能，找到合适的技能装进你的专家，它就能多一项本事。

## 怎么找现成的技能

技能宝典按 13 个分类标签组织：**我创建的 / 精选 / 效率 / 创作 / 知识 / 搜索 / 营销 / 开发 / 数据 / 协作 / 自动化 / 安全 / 生活**。

- 已经知道自己要什么，用右上角搜索框，输入关键词比如"视频""PDF""邮件"，直接定位。
- 不确定从哪开始，先看**精选**分类——使用频率最高、综合评价最好的技能都在这里。
- **自动化**分类是重复性工作的克星，能把固定流程跑起来；**创作**分类覆盖从文案到视频脚本到图片设计的内容生产；**搜索**分类可以一个技能多个渠道同时搜（网页、论文、B站视频、图片）。

![技能宝典列表页](/screenshots/p18-skills-library.png)

## 把你的重复工作变成一个专属技能

每周整理竞品动态、每次发文前做 SEO 检查、固定格式的周报生成……这类重复工作完全可以变成你的专属技能，以后一键调用，不用每次重新描述需求。

**操作方式**：

1. 在技能页面点击"创建技能"
2. 用自然语言描述你想自动化的工作内容
3. 系统帮你生成对应的技能配置
4. 保存后出现在"我创建的"分类里，随时可以装进任意专家使用

创建好的技能可以反复调用，专家直接按你设定好的方式执行，不需要你每次重新说一遍要求。

## 专家的自主学习：让技能库自己变得更整洁

除了手动创建技能，纳米Work还有一套让专家自我优化的机制：

**专家自主学习**：开启后，助理会根据你的使用习惯和反馈不断调整自己的工作方式。这个过程如果触发模型调用，会消耗算力豆。

- **任务复盘**：开启后，助理会自动复盘近期的任务过程，把可复用的经验补充到对应的技能中。相当于你的AI同事每天下班前做个工作总结，把学到的东西记下来，下次干得更好。
- **技能整理**（依赖任务复盘开启）：开启后，助理会定期合并重复技能、归档过时内容，保持技能库清晰好用。技能装多了难免乱，这个功能帮你自动收拾。

![专家自主学习设置面板](/screenshots/p18-expert-learning.png)

如果你担心自主学习把专家"改得面目全非"，不用担心——每一次修改都有版本记录，可以回溯到任意历史版本；也可以随时点击"恢复出厂设置"，回到初始版本。

## 从个人技能到企业级共享：能力沉淀

前面讲的都是"你自己"的技能积累，但纳米Work企业版更进一步的价值在于**组织级的能力沉淀**：个人搭建的专家、技能、任务默认对外公开，全组织可用——**1人摸索，全组织受益**。

这意味着：

- 一个人摸索出来的高效工作方法（比如某个岗位的报告生成套路），一旦沉淀成技能，其他同事不需要重新摸索一遍，直接复用。
- 团队模块可以查看和使用同事公开的专家、技能、任务、项目；公开的任务可以做同款复用优秀经验；公开的项目可以申请协同加入。

这跟[第14章](</第二篇 实战案例/第14章 攒资产>)讲的"人会离职，能力留下来"是同一个逻辑，只是这里强调的是**横向的团队共享**，而不只是纵向的个人经验沉淀。一个骨干员工摸索出来的方法，不需要等到他离职才被写进文档，而是可以在他还在职的时候，就变成全公司随时能调用的能力。
