# 附录C · 渠道合作伙伴专区

这一节面向想要成为纳米Work企业版渠道商、代理商，或者希望提供实施服务的伙伴。

## 纳米Work的合作生态包含哪些角色

纳米Work的企业级服务，除了产品本身，还配套了让企业真正把产品用起来的交付体系：

- **ADE AI 培训**：帮助企业每个人学会指挥自己的专家军团，把军团战力真正激活，而不是账号开通了却没人会用。
- **FDE AI 陪跑**：陪企业把军团用出真实业绩，把"为你工作"落到实际的投入产出结果上。

这两类配套服务，正是纳米Work区别于"卖账号就走"的纯 SaaS 产品的关键——买了账号只是第一步，能不能真正用出效果，需要专业的培训和陪跑支持。

## 渠道合作的几种方式

如果你是渠道商、实施服务提供方，或者具备某个行业的专业背景（比如法律、金融、交通等垂直领域），可以考虑的合作方向包括：

- **产品渠道分销**：帮助企业客户了解、采购纳米Work企业版。
- **实施陪跑服务**：为企业客户提供上手培训、场景搭建、业务陪跑等服务。
- **行业专家合作**：如果你在某个垂直行业有深厚的业务经验，可以参与行业专版的场景设计和落地，具体合作模式以实际洽谈为准。
