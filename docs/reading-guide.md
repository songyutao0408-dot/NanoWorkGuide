# 阅读指南

## 四段路径，按你的目标进入

### PART 01 · 第1—8章：先把纳米Work用起来

适合完全没用过的新用户。跟着走一遍，能独立完成账号注册到第一次任务交付。

→ [第一篇 快速上手](</第一篇 快速上手/>)

### PART 02 · 第9—14章：进入真实场景

已经会基本操作，想看别人是怎么把纳米Work用到具体业务里的。按"写材料、出报表、做物料、查风险、盯经营、攒资产"六类场景组织。

→ [第二篇 实战案例](</第二篇 实战案例/>)

想让纳米Work从"帮我做一次"变成"持续帮我做"。自动执行、定时任务、技能沉淀、安全合规、团队协作都在这里。

→ [第三篇 核心能力深挖](</第三篇 核心能力深挖/>)

想知道具体到自己岗位、自己行业该怎么落地。

→ [第四篇 岗位与行业落地](</第四篇 岗位与行业落地/>)
