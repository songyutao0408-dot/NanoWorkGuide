# 第二篇 · 实战案例

这一篇是整本手册的主体。

我们不按功能模块讲，而是按**企业老板和团队每天真实会遇到的六类活儿**来组织：写材料、出报表、做物料、查风险、盯经营、攒资产。每一类下面都是可复现的真实案例——用了哪个专家、怎么操作、最终拿到了什么结果，而不是抽象的功能介绍。

案例收录优先选取**企业级 / 团队级**的真实使用场景，个人化案例作为补充。

## 本篇章节

- [第9章 写材料](<./第9章 写材料>)：投标方案、述职汇报、教材章节、周报月报
- [第10章 出报表](<./第10章 出报表>)：财务表、造价测算、合规台账、经营看板
- [第11章 做物料](<./第11章 做物料>)：宣传片、品牌IP、推广套图、PPT与官网
- [第12章 查风险](<./第12章 查风险>)：招标排查、合同评审、合规巡检
- [第13章 盯经营](<./第13章 盯经营>)：商机线索、行业周报、业务日报
- [第14章 攒资产](<./第14章 攒资产>)：自建专家、技能沉淀、知识库积累
