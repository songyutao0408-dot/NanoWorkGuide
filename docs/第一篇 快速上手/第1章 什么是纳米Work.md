# 第1章 · 什么是纳米Work

## 一句话说清楚

纳米Work是专为企业打造的新一代智能体工作平台。从老板到员工，每个人都能配一支专属的 AI 专家军团，7×24 不眠不休地为你工作。

这句话拆开看，有三层意思：

- **不是给个人用的办公搭子，是给企业用的工作平台**。它不是"帮你写一封邮件"级别的小工具，而是能承接投标方案、财务分析、经营决策这类真金白银业务的工作台。
- **不是一个 AI，是一整支军团**。老板有老板的军团（谋划、盯防、决策），员工有员工的军团（干活、执行、冲锋），一个企业里可以同时运转多支军团。
- **不是上班时间才干活**。你下班了，你的专家团还在云端继续工作——定时任务、自动巡检、持续监控，这些都不需要你守在电脑前。

## 它能帮你做什么

如果不讲概念，只说日常经营里会遇到的活儿，大致是这六类：

| 场景 | 具体是什么 |
|---|---|
| **写材料** | 投标方案、述职汇报、教材章节、周报月报，这类要交出去的正式文档 |
| **出报表** | 财务表、造价测算、合规台账、经营看板，这类要算清楚的数字 |
| **做物料** | 宣传片、品牌IP、推广套图、PPT与官网，这类要拿出去的门面 |
| **查风险** | 招标排查、合同评审、合规巡检，这类需要有人替你把关的事 |
| **盯经营** | 商机线索、行业周报、业务日报，这类需要每天有人盯着的事 |
| **攒资产** | 自建专家、技能沉淀、知识库积累，这类干完了要留在公司的能力 |

这六类不是功能列表，而是真实企业主和员工在用纳米Work时最常做的事——具体的真实案例，我们会在[第二篇 实战案例](</第二篇 实战案例/>)里逐一展开。

## 它和普通AI聊天工具的区别

普通的 AI 对话工具，你问一句它答一句，聊完就结束，下一次对话从零开始。纳米Work不是这样：

- **有专业分工**：不是一个什么都懂一点的通用助手，而是有专门做财务分析的专家、专门做招投标的专家、专门盯经营风险的专家，各司其职。
- **有记忆、能沉淀**：你上传过的资料、定过的业务口径，专家会一直记得，不用每次都重新交代背景。
- **能持续运转**：定时任务可以让专家在你关掉客户端之后，依然在云端按计划工作，到点自动推送结果。
- **能力可以留在公司**：员工离职，他训练出来的专属专家、沉淀的技能和知识库，可以留在企业里被全公司复用，不会随人走失。

## 谁在用、用来做什么

从目前的真实使用情况看，用纳米Work的主要是三类人：

- **中小企业主/创业者**：用来做投标方案、商机整理、经营决策、品牌营销物料，本质是把"一个人干出一支团队的活"变成可能。
- **职场精英**：用来做PPT汇报、报告撰写、数据财务分析、竞品行业情报，把日常工作里重复消耗精力的部分交出去。
- **OPC（园区/初创/开发者）**：用来快速建站、验证产品想法，一个人也能推进产品从零到上线。
