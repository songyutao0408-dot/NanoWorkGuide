# 第3章 · 认识主界面与对话模式

## 首页：你和 AI 专家开始对话的地方

首页是整个纳米Work的起点。进来就能干活，不需要先做任何配置。

有两条路径可以开始一次任务：

### 路径一：选一个专家

1. 在首页找到符合你需求的专家（比如做战略决策用"第一性原理策略专家"，还不确定要用哪个专家就用"专家教练"）。
2. 点击专家卡片进入对话界面，在底部输入框写清楚你的任务，按回车发送。
3. 专家会按它自己的专业逻辑直接执行，不需要你再额外选择模式。
4. 任务开始后，可以在左侧"任务"里看进度，在"云盘"里取最终成果文件。

![首页选择专家界面](/screenshots/p3-choose-expert.png)

输入框支持用 `/` 快速引用云盘里的文件，或者调用已经装好的技能——给专家更多背景信息，它干活会更准。

### 路径二：不选专家，直接用纳米AI助理

如果你不点任何专家卡片，直接在首页底部输入框打字发任务，默认会由**纳米AI助理**接活。

纳米AI助理是纳米Work的默认通用助手，如果你不确定该用哪个专家，或者任务比较杂、不好归到某个专业领域，直接用它就能覆盖大多数场景。

所有对话都会自动归集到左侧"任务"列表里，按时间排列，随时可以找回继续，也支持搜索和删除。

![历史任务列表](/screenshots/p3-task-history.png)

## 三种对话模式：标准 / 计划 / 目标

选对模式，是用好纳米Work很重要的一步。三种模式的区别，本质是"你想让专家花多少精力想清楚再动手"：

![三种对话模式选择](/screenshots/p3-mode-select-2.png)

### 🟢 标准模式

快问快答，直接给结果。算力消耗最低，适合任务清晰、结果简单的场景。

**适合什么**：你已经把要做的事想清楚了，专家只需要执行，不需要它帮你多想。

### 🟢 计划模式

深挖、验证、推演，有料有据的结论。专家会主动搜索信息、多角度交叉验证，而不是直接给答案。

**典型场景**：
- 竞品分析报告
- 行业深度调研
- 合同风险审查
- 方案策划与论证

**示例指令**：
- "分析新能源汽车行业 2025 年 Q2 的竞争格局，引用公开数据"
- "审查这份合同，找出所有法律风险点，给出修改建议"

算力消耗：较多。

### 🟢 目标模式

你只说目标，专家自己规划、执行、迭代，干到完成为止。不需要你把步骤想清楚，专家会自己拆解任务、逐步推进，遇到问题自主调整。**关掉客户端它在云端继续跑**，早上起来看结果就行。

**典型场景**：
- 从零搭建一个系统
- 持续监控某个平台并筛选信息
- 完成一整套品牌方案
- 多工具协作的复杂工程

**示例指令**：
- "帮我搭建一个酒店智能调价系统，能对接携程和美团的数据"
- "每天盯着广东省公共资源交易平台，监理费超 100 万的项目立即通知我"

算力消耗：可能较多。

### 怎么选？

一个简单的判断方式：

- 事情简单、你知道要什么 → **标准模式**
- 事情需要论证、需要有依据的结论 → **计划模式**
- 事情复杂、需要持续推进、你自己也说不清具体步骤 → **目标模式**

如果实在拿不准，直接用纳米AI助理 + 计划模式，能覆盖大多数不确定的场景。
