# 第一篇 · 快速上手

这一篇解决一件事：**让你从零开始，独立跑通第一次成功**。

不讲概念，只讲操作。你会依次搞清楚：账号怎么注册登录、对话模式怎么选、专家团怎么用、知识库和云盘怎么管理、算力豆怎么算，最后用一个真实任务把这些串起来。

读完这一篇，你应该能独立完成：**给纳米Work一个具体的活儿，拿到一份可以直接用的产出。**
