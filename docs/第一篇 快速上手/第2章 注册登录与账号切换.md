# 第2章 · 注册登录与账号切换

## 入口

纳米Work企业版有两种使用方式：

- **网页版**：浏览器访问 `https://www.namiwork.cn/`，打开即用，不需要安装任何东西。
- **Windows 客户端**：适合日常高频使用，体验更接近本地软件。

## 安装 Windows 客户端

如果你选择安装客户端，流程是这样的：

1. **启动安装程序**：双击安装包，系统会弹出用户账户控制对话框，选择"是"，允许程序安装。
2. **选择安装方式**：
   - 点击**快速安装**，默认装在 C 盘，适合大多数人，不用想太多。
   - 如果你对安装路径有要求，点右下角**自定义安装**，自己选路径。
3. **等待安装完成**：安装程序会自动运行，大概需要 2-3 分钟。装完会自动跳转到启动页。

   ![纳米Work企业版安装启动页](/screenshots/p2-installing-splash.png)

整个过程不需要任何技术背景，跟装普通软件没有区别。

## 企业版购买与开通

在你能登录之前，需要企业先完成购买和后台配置，这一步通常是企业管理员来做：

- **购买入口**：可以添加企业版咨询微信 `nicolelee5`，或联系你对接的销售顾问。
- **购买完成后**：管理员进入企业管理后台，做人员管理、席位分配、算力管理、模型分配等配置。
- **配置完成后**：员工才能登录企业版账号开始使用。

如果你是普通员工，这一步不用你操心，等企业管理员配置好、给你开通账号即可。

## 注册登录

1. 打开客户端或网页版，选择**企业版**。
2. 用**手机号**进行登录。
3. 如果你同时属于多个团队（比如既在公司团队、又有自己的个人账号），登录时会让你选择要进入哪个团队。

![注册登录界面](/screenshots/p2-login-1.png)

## 切换团队/个人账号

纳米Work支持"个人版"和"企业版"两种身份，登录弹窗顶部就能直接切换：

![个人版/企业版切换](/screenshots/p2-login-2-switch-team.png)

- 弹窗顶部的"个人版 / 企业版"标签，点击即可切换要登录的身份。
- 如果你之前登录过，弹窗会显示"上次登录"提示，方便快速找回。
- 已经登录企业版后，如果需要切换团队或切换到个人账号，可以点击页面**左下角头像上方的"…"**，同样能找到切换入口。

这个设计对应的是纳米Work"1+N账号"的模式——同一个人可能既有企业账号处理公司业务，也想用个人账号做一些私人任务，两边互不干扰，随时可以切换。
